# Demo Familia Barbershop

Landing conceptual para **Familia Barbershop**, desarrollada por Ross Digital Studio.

## Enfoque
- estética clásica de barbershop
- negro, dorado y blanco
- responsive para mobile, tablet y desktop
- animaciones al hacer scroll
- servicios, experiencia, trabajos, beneficios, horarios y ubicación
- WhatsApp y cómo llegar como CTAs principales
- barra fija inferior en mobile

## Datos públicos utilizados
- Av. Directorio 1715, CABA
- Lunes: 11:00 a 20:00
- Martes a sábados: 10:00 a 20:00
- Wi‑Fi
- métodos de pago
- Instagram: @familiabarbershop1715
- WhatsApp publicado en bio

## Nota
Las imágenes son ilustrativas y de stock. La demo incluye `noindex,nofollow` y no representa una web oficial del negocio.
